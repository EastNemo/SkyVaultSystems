Privacy Policy

Last updated: Demo / Educational Version

SkyVault Systems is a demonstration platform developed as part of an academic project. The platform is not a commercial service and is not intended for real-world deployment.

Data Handling

The Vault interface performs client-side encryption as a functional demonstration. Files selected by the user are processed locally in the browser and are not uploaded to any remote server or stored online.

SkyVault does not collect account data, personal information, or user-identifying details. Any session identifiers used in the demo are temporary and exist only for presentation purposes.

Encryption Disclaimer

The encryption mechanism used in this prototype is simplified and is not intended for real-world security. It should not be used to protect sensitive or confidential data.

Third-Party Services

The platform does not use cookies, analytics, or third-party tracking tools.

Contact

Questions regarding this project can be submitted via the Contact page. Responses are handled only for academic demonstration purposes.

This Privacy Policy applies only to the demo version of SkyVault Systems.
